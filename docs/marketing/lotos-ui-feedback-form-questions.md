# LotOS UI Feedback Questions

Usar estas preguntas con testers de Foundation, Creator Pass o Founder Pass. No guardar PII sin aviso.

1. Que entendiste que vende LotOS UI?
2. Que pantalla se sintio mas vendible?
3. Que se sintio todavia plantilla o demasiado free?
4. Pagarias Pro Studio? Por que?
5. Que te bloquearia antes de usarlo en un proyecto real?

## Ruta publica

La ruta `/feedback` muestra estas preguntas sin backend y dirige a soporte/canal acordado.
