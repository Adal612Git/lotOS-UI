# LotOS UI Launch Kit - 2026-05-25

## Posicionamiento

LotOS UI convierte pantallas generadas por IA en interfaces listas para vender: dashboards, CRUDs, reportes y product surfaces con una ruta gratuita clara y frontera premium controlada.

## Tagline

De pantalla generada a producto vendible.

## Una frase

LotOS UI turns AI-generated screens into product-ready interfaces with premium dashboards, CRUDs, reports and product surfaces.

## Un parrafo

LotOS UI no compite como otra libreria de botones. Es una capa de product surfaces para que un prototipo generado por IA pueda parecer una pantalla real de negocio: datos, acciones, estados, reportes, acceso promocional y rutas premium que se pueden vender sin regalar el vault privado.

## Valor

- Product surfaces, not isolated buttons.
- Foundation gratis para explorar sin romper premium.
- Pro Studio para dashboards, CRUDs, CommandShell, DataGridPro y ReportSurface.
- Full Signature para la suite completa y assets privados autorizados.
- Creator Pass y Founder Pass para testers, creadores y aliados seleccionados.

## Foundation

Incluye demos publicas, componentes base, previews, documentacion publica y before/after. No incluye descargas premium ni Full Signature.

## Pro Studio

Incluye superficies completas, kits premium autorizados, DataGridPro, CommandShell, ReportSurface y flujos que se sienten mas cerca de producto que de maqueta.

## Full Signature

Es el nivel mas delicado. Debe usarse para acceso completo, gifts manuales de bajo volumen o compradores con acceso autorizado.

## Creator Pass

Pase temporal para creadores/testers. Recomendado: `PRO_TRIAL`, 14 dias, `maxClaims: 1`.

## Founder Pass

Pase temporal para aliados tempranos. Recomendado: `PRO_TRIAL`, 30 dias, `maxClaims: 1`.

## Post largo

Estoy preparando LotOS UI como una forma de convertir pantallas generadas por IA en interfaces mas cercanas a producto real. La idea no es vender botones bonitos ni otra plantilla. La idea es mostrar product surfaces: dashboards, CRUDs, reportes, acciones, estados y handoff visual para que una demo se vea defendible frente a un cliente.

Foundation sera gratis para explorar. Pro Studio desbloquea superficies mas completas. Full Signature queda protegido para la suite premium. Para testers y aliados voy a usar Creator Passes y Founder Passes con expiracion, revocacion y limite de claims.

Busco feedback directo: que se entiende, que se ve vendible, que aun se siente plantilla y que bloquearia pagar Pro Studio.
