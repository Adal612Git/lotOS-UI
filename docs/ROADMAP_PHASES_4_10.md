# Roadmap Phases 4-10

## Phase 4: Visual Regression And Design System Maturity

1. Screenshot visual regression for public and Pro React packages.
2. Component state matrix for empty, loading, error, focus, dark, light, and responsive states.
3. Free/pro source split with package leak gates.
4. Storybook/showcase as the design contract.

## Phase 5: Real Multi-Runtime Adapters

5. Productize Laravel Blade, Django/Jinja, and .NET Razor first.
6. Add smoke tests and runnable examples per adapter.
7. Standardize tokens and props across React, web components, and server templates.
8. Keep planned runtimes explicitly marked as planned.

## Phase 6: Marketplace And Monetizable Templates

9. Turn registry templates into a filterable catalog.
10. Package five initial sellable kits.
11. Add screenshots, license metadata, requirements, and delivery assets.
12. Connect vault downloads to generated bundles.

## Phase 7: Enterprise/Admin/Team

13. Add organizations, members, seats, roles, and audit logs.
14. Separate internal owner from buyer/team admin.
15. Build entitlement/admin operations.
16. Define enterprise guided offer and support policy.

## Phase 8: AI Agent Builder

17. Turn `/ai` into a registry-backed planner.
18. Generate specs and checklists before generating code.

## Phase 9: Plugin Ecosystem

19. Define plugin manifests, permissions, validation, and private/public registries.

## Phase 10: Public Launch

20. Run public-release gates, publish public packages, validate real purchase, and launch only after premium split, legal/support, pricing, DNS, and security rotation are complete.
