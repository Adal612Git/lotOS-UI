# LotOS Desktop .NET Demo

Runnable desktop demo for LotOS UI using WinForms.

## Run

```powershell
cd apps\desktop-dotnet-demo
dotnet run
```

## Build

```powershell
dotnet build
```

## Publish

```powershell
dotnet publish -c Release -r win-x64 --self-contained false
```

## Build script

```powershell
./build.ps1
```
