# Installation

Before installing anything, read [Start Here](/docs/start-here) if you need the shortest path by use case.

---

## Requirements

- **Node.js** 18+
- **React** 19+ (peer dependency)
- **Package manager**: npm, pnpm, or yarn

---

## Install the stable package

```bash
npm install @lotosui/claude-arm
# or
pnpm add @lotosui/claude-arm
# or
yarn add @lotosui/claude-arm
```

---

## Setup: Next.js (App Router)

**1. Import styles in your root layout:**

```tsx
// app/layout.tsx
import '@lotosui/claude-arm/styles.css';
import type { Metadata } from 'next';

export const metadata: Metadata = {
  title: 'My App',
};

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  );
}
```

**2. Use components in any page or component:**

```tsx
// app/page.tsx
import { Button, Card, Badge } from '@lotosui/claude-arm';

export default function Page() {
  return (
    <Card>
      <Badge variant="success">Active</Badge>
      <h2>Welcome to your dashboard</h2>
      <Button variant="primary">Get Started</Button>
      <Button variant="ghost">Learn More</Button>
    </Card>
  );
}
```

**3. If using Tailwind CSS**, add the component paths to your `tailwind.config.ts`:

```ts
// tailwind.config.ts
import type { Config } from 'tailwindcss';

const config: Config = {
  content: [
    './app/**/*.{ts,tsx}',
    './components/**/*.{ts,tsx}',
    './node_modules/@lotosui/claude-arm/dist/**/*.js', // include LotOS components
  ],
  theme: {
    extend: {},
  },
  plugins: [],
};

export default config;
```

## Setup: Vite (React)

**1. Install and configure:**

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install @lotosui/claude-arm
```

**2. Import styles in `main.tsx`:**

```tsx
// src/main.tsx
import '@lotosui/claude-arm/styles.css';
import React from 'react';
import ReactDOM from 'react-dom/client';
import App from './App.tsx';

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
);
```

**3. Use components:**

```tsx
// src/App.tsx
import { Button, Card, Input } from '@lotosui/claude-arm';

function App() {
  return (
    <div style={{ padding: '2rem' }}>
      <Card>
        <Input placeholder="Search..." />
        <Button variant="primary">Search</Button>
      </Card>
    </div>
  );
}

export default App;
```

## Theming

LotOS UI uses CSS custom properties for its design tokens. Override them in your global CSS to match your brand:

```css
/* globals.css */
:root {
  /* Accent — default: Electric Red #E94560 */
  --lotos-accent: #3b82f6;          /* override to blue */
  --lotos-accent-hover: #2563eb;
  --lotos-accent-active: #1d4ed8;
  --lotos-accent-subtle: rgba(59, 130, 246, 0.12);
  --lotos-accent-glow: rgba(59, 130, 246, 0.35);
  --lotos-accent-glow-sm: rgba(59, 130, 246, 0.20);

  /* Backgrounds */
  --lotos-bg-primary: #ffffff;      /* override to light */
  --lotos-bg-card: #f8fafc;

  /* Foreground */
  --lotos-fg-primary: #0f172a;
  --lotos-fg-secondary: rgba(15, 23, 42, 0.72);
}
```

The design system is dark-first by default (`#0D0F1E` background). Overriding `--lotos-bg-primary` and foreground tokens is all you need to create a light theme.

## MCP integration for AI agents

Run the MCP server to expose component contracts to AI tools:

```bash
pnpm --filter @lotosui/core build
node packages/core/dist/mcp/server.js
```

Query a component contract:

```bash
curl http://localhost:3100/components/button
```

The MCP server returns JSON schemas that AI agents can use to generate valid component code without hallucinating props or variants.

## Troubleshooting

**Styles not applying:**
- Confirm `@lotosui/claude-arm/styles.css` is imported before your component code.
- In Next.js, this import must be in `layout.tsx` (not inside a component).

**TypeScript errors on props:**
- Run `pnpm --filter @lotosui/claude-arm build` to generate updated type declarations.
- Ensure `@types/react` is version 19+.

**Dark mode not working:**
- LotOS UI is dark-first. The `color-scheme: dark light` is set on `:root`.
- To force light mode, add `color-scheme: light` to your own `:root` after the import.

**Tailwind classes conflicting:**
- LotOS uses prefixed classes (`.lotos-btn`, `.lotos-badge`). No conflicts with default Tailwind.
- If using Tailwind's `preflight`, the LotOS reset is compatible.

## Design + functional checklist

Before building a new screen:

1. Choose a runtime and pattern from MCP `/runtimes` + `/patterns`.
2. Apply design tokens and pattern section structure.
3. Generate framework-safe snippets from component schemas.
4. Validate with Sentinel warnings and runtime tests.

**En espanol:**

Antes de construir una nueva pantalla:

1. Elige un runtime y patron desde MCP `/runtimes` + `/patterns`.
2. Aplica design tokens y estructura de seccion del patron.
3. Genera snippets seguros para el framework desde los schemas de componentes.
4. Valida con las advertencias de Sentinel y tests de runtime.
