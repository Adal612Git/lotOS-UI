# Modal

The `Modal` component is a fully accessible dialog. It implements:

- **Focus trap** — `Tab` cycles within the modal only
- **Scroll lock** — body scroll is prevented while open
- **Keyboard close** — `Escape` closes the dialog (configurable)
- **Backdrop close** — clicking outside closes the dialog (configurable)
- `aria-modal`, `aria-labelledby`, `aria-describedby` — full screen reader support

## Import

```tsx
import { Modal } from '@lotos/claude-arm'
```

## Basic usage

```tsx
function MyComponent() {
  const [open, setOpen] = useState(false)

  return (
    <>
      <Button onClick={() => setOpen(true)}>Open modal</Button>

      <Modal
        open={open}
        onClose={() => setOpen(false)}
        title="Confirm action"
        description="This action cannot be undone."
      >
        <p>Are you sure you want to delete this item?</p>
      </Modal>
    </>
  )
}
```

## With Modal.Footer

Use `Modal.Footer` for action buttons:

```tsx
<Modal
  open={isOpen}
  onClose={handleClose}
  title="Confirm deletion"
  description="This will permanently delete the record."
  size="sm"
>
  <p>All associated data will be removed.</p>
  <Modal.Footer>
    <Button variant="ghost" onClick={handleClose}>Cancel</Button>
    <Button variant="destructive" onClick={handleDelete}>Delete</Button>
  </Modal.Footer>
</Modal>
```

## Using the `footer` prop

Alternatively, pass `footer` as a prop:

```tsx
<Modal
  open={isOpen}
  onClose={handleClose}
  title="Edit profile"
  footer={
    <>
      <Button variant="ghost" onClick={handleClose}>Cancel</Button>
      <Button variant="primary" type="submit">Save changes</Button>
    </>
  }
>
  <Input label="Full name" />
  <Input type="email" label="Email" />
</Modal>
```

## Preventing accidental close

For critical confirmations, disable backdrop and Escape close:

```tsx
<Modal
  open={open}
  onClose={handleClose}
  title="Delete account"
  closeOnBackdropClick={false}
  closeOnEscape={false}
>
  <p>This action is permanent and cannot be undone.</p>
  <Modal.Footer>
    <Button variant="ghost" onClick={handleClose}>Cancel</Button>
    <Button variant="destructive" onClick={handleDeleteAccount}>
      Yes, delete my account
    </Button>
  </Modal.Footer>
</Modal>
```

## Sizes

```tsx
<Modal size="sm" ...>   {/* max-w-sm  */}
<Modal size="md" ...>   {/* max-w-md  (default) */}
<Modal size="lg" ...>   {/* max-w-lg  */}
<Modal size="xl" ...>   {/* max-w-2xl */}
<Modal size="full" ...> {/* full screen */}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `open` | `boolean` | — | **Required** — controls visibility |
| `onClose` | `() => void` | — | **Required** — close handler |
| `title` | `string` | — | **Required** — used as `aria-labelledby` |
| `description` | `string` | — | Subtitle text, used as `aria-describedby` |
| `size` | `'sm' \| 'md' \| 'lg' \| 'xl' \| 'full'` | `'md'` | Dialog width |
| `closeOnBackdropClick` | `boolean` | `true` | Close when clicking backdrop |
| `closeOnEscape` | `boolean` | `true` | Close on `Escape` key |
| `showCloseButton` | `boolean` | `true` | Show × button in header |
| `footer` | `ReactNode` | — | Footer content (alternative to `Modal.Footer`) |

## Anti-hallucination rules (MCP)

- ✅ `title` is **required** — it provides `aria-labelledby`
- ❌ Do NOT manage `open` state inside the modal — always use external state
- ❌ For critical confirmations, set `closeOnBackdropClick={false}` to prevent accidental dismissal

## Accessibility

- `role="dialog"` + `aria-modal="true"` on the dialog element
- Focus moves to the first focusable element on open
- Focus is trapped inside the dialog until closed
- Body scroll is locked while the modal is open
- `Escape` closes the modal (disable with `closeOnEscape={false}`)
