# Toast

`Toast` is an ephemeral notification surface for success, warning, error, and info feedback.

## Example

```tsx
import { Toast } from '@lotosui/claude-arm';

<Toast
  variant="success"
  title="Deployment created"
  description="The rollout was queued successfully."
/>
```

## Notes

- Use concise confirmation copy.
- Do not rely on toasts alone for blocking errors.
