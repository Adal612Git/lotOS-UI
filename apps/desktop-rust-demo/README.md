# LotOS UI Rust Desktop Demo

This demo is a real Rust desktop shell using `eframe` / `egui`.

## What it includes

- KPI cards
- runtime matrix
- modal-like delivery panel
- action controls

## Run locally

```bash
cargo run
```

## Build release

```bash
cargo build --release
```

The release binary will be available under:

- `target/release/lotos-desktop-rust-demo`
