# @lotosui/core

Pure TypeScript contracts for LotOS UI: tokens, schemas, runtime catalogs, patterns, and MCP transport.

## Public Exports

- `@lotosui/core`
- `@lotosui/core/tokens`
- `@lotosui/core/schemas`
- `@lotosui/core/runtime`
- `@lotosui/core/mcp`

## Validation

```bash
pnpm --filter @lotosui/core build
pnpm --filter @lotosui/core test
```
