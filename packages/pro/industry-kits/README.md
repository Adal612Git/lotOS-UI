# Pro Industry Kits

Premium domain presets that package component guidance, copy, and screen structure for specific verticals.

Current kits:

- Finance Ops
- Health Ops
- Excel Lotus Grid
- OpenOffice Calc Command

These kits are intended to accelerate commercial delivery while keeping the open-source core general-purpose.

Spreadsheet kits are designed to make ugly spreadsheet workflows feel premium without forcing a full application rewrite.
