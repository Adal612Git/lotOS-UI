# Known Failure Patterns

- Treating `LOTOS_OWNER_EMAILS` as the buyer login allowlist blocks real buyers after Lemon checkout.
- Saying "27 components" without clarifying the free/pro split confuses public package users.
- Adding a new runtime without maturity status makes agents overstate support.
- Editing pricing copy without updating commercial manifests creates drift.
- Adding web components without package subpath exports makes imports fail.
- Keeping premium source in a public repo exposes paid code even when the vault works.
- Relying only on page copy for AI context forces agents to scan huge files and hallucinate.
