## Regla de uso

Si algo se va a prometer en marketing, primero debe poder defenderse con:

1. Un archivo real en el repo o un flujo real en produccion.
2. Una ruta clara de entrega para el cliente.
3. Una diferencia visible frente a la capa MIT gratuita.
4. Una politica clara de acceso, cancelacion y soporte.
