# Strategy Workspace

This folder is the canonical home for non-code product strategy work.

## Layout

- `market-intel/studies`: structured market studies, competitor teardowns, and pricing notes.
- `market-intel/movements`: weekly signals, ecosystem shifts, and competitor launches.
- `market-intel/templates`: reusable templates to keep strategy work consistent.
- `patterns`: multi-runtime UX and design pattern references.

## Naming Convention

Use `YYYY-MM-DD_topic_owner.ext` for all new files.

Examples:

- `2026-02-25_php-ui-gap_rick.md`
- `2026-03-03_django-admin-redesign_team.md`
